### A repository for projects 
In the Projects folder you will find subfolders containing projects that i have been working on.
* Projects/Computer_vision/CV_project - Final project of computer vision course. Runns a structure from motion poipeline. 
* Projects/Computer_vision/CNN - Final project of image analysis course. Runns a convolutional neural network to classify trees based on images of bark. 
* Projects/reinforcement_learning - Runs a script where two agents play tic tac toe against eachother
* Projects/Stochastic_optimization - Code for training a neural network with genetic algorithms
